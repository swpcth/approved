ระบบตรวจสอบหน่วยคะแนนการศึกษาต่อเนื่อง

โครงการที่สภาวิชาชีพสังคมสงเคราะห์รับรอง

ยังไม่ได้ตั้งค่า API_BASE_URL ในไฟล์ app.js — โปรดใส่ URL ของ Google Apps Script Web App ที่ deploy แล้ว (ลงท้ายด้วย /exec)
ระบบตรวจสอบประวัติการลงทะเบียนเข้าร่วมโครงการ/อบรม สภาวิชาชีพสังคมสงเคราะห์ ตรวจสอบประวัติรายชื่อผู้เข้าร่วมโครงการ/อบรม ของสภาวิชาชีพฯ และสภาฯ ได้ดำเนินการนำเข้าหน่วยคะแนนให้เรียบร้อยแล้ว
คำอธิบายหมายเหตุและสถานะโครงการในระบบ

คอลัมน์ "หมายเหตุ" (แท็บค้นหาโครงการ/หน่วยคะแนน)

ผู้จัดนำเข้าคะแนนให้ผู้เข้าร่วมแล้ว : ทางผู้จัดได้นำเข้าหน่วยคะแนนให้สมาชิกผ่านระบบเรียบร้อยแล้ว หากไม่พบชื่อ ให้ติดต่อผู้จัดโครงการโดยตรง

อยู่ระหว่างขอค่าคะแนน : โครงการอยู่ระหว่างดำเนินการขอหน่วยคะแนน ยังไม่สามารถนำเข้าคะแนนให้สมาชิกได้ในขณะนี้ กรุณาตรวจสอบอีกครั้งในภายหลัง

ประกาศรายชื่อ : ทางผู้จัดประกาศรายชื่อผู้เข้าร่วม (ไม่ได้นำเข้าคะแนนให้) ให้สมาชิก ดาวน์โหลดรายชื่อ จากช่อง "ค้นหาประกาศรายชื่อผู้เข้าอบรม" เพื่อนำไปแนบเพิ่มกิจกรรมและกรอกค่าคะแนนด้วยตนเองในเว็บไซต์การศึกษาต่อเนื่อง

- ไม่ได้ระบุหมายเหตุ : สมาชิกต้องแนบหลักฐาน (เช่น ใบประกาศฯ/Certificate พร้อมกำหนดการ) เพื่อขอรับค่าคะแนนผ่านระบบการศึกษาต่อเนื่องด้วยตนเอง

ดาวน์โหลด : มีไฟล์/ลิงก์ประกาศรายชื่อผู้เข้าร่วมให้ดาวน์โหลดโดยตรง กดปุ่มเพื่อเปิดไฟล์ได้ทันที

นำเข้าค่าคะแนนแล้ว : ผู้จัดได้นำเข้าคะแนนให้สมาชิกในระบบเรียบร้อยแล้ว ไม่ต้องดาวน์โหลดไฟล์เพิ่ม หากไม่พบชื่อ ให้ติดต่อผู้จัดโครงการโดยตรง
